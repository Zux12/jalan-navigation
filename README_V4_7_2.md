# Jalan V4.7.2 — Navigation Menu

Upload all frontend files to the existing Jalan GitHub Pages repository. No changes to Heroku or MongoDB.

During GPS or simulation, tap **Menu** in the navigation HUD to open the main Jalan panel. The panel overlays the lower part of the screen on phones and appears on the left on desktop. Close menu to return without stopping navigation. The navigation HUD remains visible.

Tests: (1) Menu in GPS (2) Shared Traffic controls reachable (3) Close retains GPS (4) Menu in simulation (5) Close retains simulation (6) iPhone scroll (7) Exit GPS resets panel (8) TomTom and voice unchanged.

Privacy: traffic sharing is opt-in. Do not interact with the menu while driving.
